Life RPG

A self-hosted personal progress tracker that turns real-life growth into an RPG-style experience, letting you log daily activities and watch your stats level up over time.

View Live Project View Source

Overview

Life RPG reframes personal development as a character sheet: 24 customizable stats span physical, intellectual, creative, social, and practical categories. Users start with a character-creation questionnaire that sets baseline levels, then log day-to-day activities in plain language to earn XP and level up over time.

Key Features

  • 24 customizable stats across five life categories
  • Character creation questionnaire for setting baseline stat levels
  • AI-powered XP allocation that reads a free-text activity log and assigns stat gains
  • Full log history with undo and individual entry deletion
  • JSON export/import for backup and restore, without ever storing API keys
  • Installable as a progressive web app for a home-screen, app-like experience

Tech Stack

React + Vite

Frontend framework and build tooling

Browser localStorage

Fully client-side, privacy-first data storage

Gemini 2.5 Flash

AI-driven XP allocation from activity descriptions

GitHub Actions

Automated CI/CD deployment to GitHub Pages

Technical Highlights

  • Entirely device-side storage design keeps personal data and API keys off any server
  • Natural-language activity logging mapped to structured stat updates via an LLM
  • PWA manifest and iPhone safe-area support for a native-feeling mobile experience
  • Automated build and deploy pipeline via GitHub Actions

Hand Theremin

A touchless digital instrument that turns your webcam into a synthesizer, using real-time hand tracking to control pitch, volume, and chords in the air.

View Source on GitHub

Overview

Hand Theremin replaces the physical theremin's antennas with a webcam and MediaPipe's hand-landmark tracking. Right-hand height controls pitch and left-hand height controls volume, letting you play notes purely through gesture. Finger counts layer in octave shifts and chord voicings, while flipping your palm switches between sine and sawtooth waveforms, turning hand motion into a fully playable, touchless instrument.

Key Features

  • Right-hand height controls pitch, left-hand height controls volume
  • Finger counts adjust octave and layer major-chord voicings, from a single root note up to extended chords
  • Palm orientation toggles between sine and sawtooth waveforms
  • Three pitch modes: continuous gliding, quantized note snapping, and a beginner-friendly zone mode with colored bands
  • On-screen reference lines and a fixed grid that stays put across octave changes
